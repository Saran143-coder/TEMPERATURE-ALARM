# 🌡️ Temperature Alarm

A simple temperature monitoring system that detects overheating using an **LM35 Temperature Sensor**. When the temperature exceeds a preset limit, an **LM358 Comparator** and **BC547 Transistor** activate an LED (or buzzer) to provide an alert.

---

## 📖 Abstract

The **Temperature Alarm** is a low-cost and reliable analog electronic project that continuously monitors temperature. The LM35 sensor measures temperature, while the LM358 comparator compares it with a preset reference voltage. If the temperature exceeds the set limit, the BC547 transistor switches ON the LED (or buzzer), providing an instant warning. This project helps protect electrical equipment from overheating and can be used in homes, industries, and laboratories.

---

## ⚙️ Working

1. LM35 senses the temperature.
2. LM358 compares it with the preset value.
3. If the temperature is above the limit, the comparator output becomes HIGH.
4. BC547 switches ON the LED (or buzzer).
5. The alarm turns OFF automatically when the temperature returns to normal.
